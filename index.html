先读到《河水向南》的第十三章

先看提示

正文里有两个常出现的人，也有一位从很多年前一直回复到现在的读者。读到连载末页以后，往下翻一翻。

展开具体走法
  1. 从首页打开《河水向南》连载帖，按「下一章」阅读公开的十三章。需要回查章节时，展开「查看完整章节目录」。
  2. 在第十三章《春天之前》读到最下方的「楼内最近回复」，点六月十一的用户名，进入公开资料。
  3. 记下小说里反复出现的二十二路、青藤文学社和《南溪青年》。第十三章还写到毕业照的日期是六月十一日。
  4. 点作者「槐序」可看她的公开主题。个人资料写着最后活动在 2008-04-13 23:58，这个时间留到后面再核对。

从读者资料找到文学社旧主页

先看提示

六月十一的发言里提到一篇被撕掉的作文和一份秋季校刊。论坛上还有人询问过文学社的招新海报，可以从那条讨论找到旧主页。

展开具体走法
  1. 在六月十一的资料页读「2006文学社作品交流」「《南溪青年》旧刊有人留着吗」和公开收藏夹，记下七中、2006秋季刊。
  2. 返回论坛首页，在搜索框输入青藤文学社，打开《学校文学社招新海报，帮忙改字》。六月十一的回复里有可点击的「南溪第七中学青藤文学社」。
  3. 进入社团主页，看「《南溪青年》校刊目录」。2006秋季刊的《树下》署名周禾，指导老师是顾槐。社团动态写着作品张贴改为先征询作者本人意见。
  4. 继续看毕业合影说明。顾槐站在后排右侧，周禾在学生队伍最边上，没有看镜头。2007秋起，文学社指导老师换为刘雯。
  5. 在本页「常用网站」点击南溪生活报。

把姓名和那个四月放到一起查

先看提示

报纸首页恢复的是普通旧闻。用校刊上的老师姓名检索，再把连载停更后的日期放进去查。读到事故报道时，还要点开它的后续。

展开具体走法
  1. 在南溪生活报搜索顾槐，打开 2008年4月15日的《七中青年教师顾槐失联，家属寻求线索》，读正文和下方读者留言。
  2. 再搜2008-04-14，打开《城北客运线上午班车雨天发生侧翻》，然后点文末后续：临时编号伤者身份核对完成。也可搜临时编号直接找4月16日的报道。
  3. 后续记载一名31岁的中学女教师，随身有出版社联系卡、打印稿取件单和两支红笔，家属于15日下午完成确认，伤者于15日凌晨去世。将这些信息与顾槐的失联报道、后面找到的招聘和打印记录一起核对。
  4. 回到顾槐失联报道，在「老蒋」的读者留言中点击南溪教师交流站。

查清突然拉开距离的那一年

先看提示

教师交流站打开时主要显示2008年的帖子。新闻留言提到的讨论在前一年，记得调整年份。

展开具体走法
  1. 年份选2007，版面可选「班主任茶座」，关键词填边界，点「筛选旧帖」。
  2. 打开《学生和老师的边界，到底怎么掌握》。读「槐树下」的回复，以及陈老师对突然推开学生的看法。
  3. 「槐树下」的签名写着「七中语文组」，其中小满书店是可点击的链接，由这里继续。
  4. 想补充作文一线，可改到「语文教研」查《学生作文公开张贴前要不要逐个确认》；想补充职业变化，可查2008年的《青年教师跨区应聘经验》。
05楼小满书店
查阅顺序 05 / 10返回目录

用校刊上的名字查留刊记录

先看提示

书店的记录按真名、笔名和刊名保存。前面已经从校刊找到了那个学生的名字，现在可以查他在店里留下了什么。

展开具体走法
  1. 在「代订／留刊记录查询」输入周禾，点「查旧记录」。
  2. 核对2006秋季校刊、《小说月报》合订本和槐序发表短篇的《江岸文艺》2007年第6期。后者记着4月12日仍未取，前面六月十一的旧帖也提到在小满询问旧刊。
  3. 查询周禾后，结果下方会多出一行活动来源，点击其中的南溪作家论坛。

首次到书店可能出现作者的自愿支持弹层，点右上角关闭或「下次一定」即可继续查阅。

进入槐序的会员旧档

先看提示

会员验证需要她常用的笔名和最常坐的公交线路。二者都在之前读过的连载与回帖里。

展开具体走法
  1. 在南溪作家论坛点「会员旧档」或「旧账号验证」。
  2. 登录名填槐序；安全问题「你最常坐哪一路公交？」填22路，点「核对」。二十二路也可通过。
  3. 在会员旧档读《想换个地方工作，出版社编辑岗有人了解吗》《长篇收尾后先给谁看》和《搬家前清理书和稿子》。可核对她已投稿、准备月底换工作，完整长篇还留着末几章尚未公开。
  4. 从求职帖中白砚的回复点击江岸文艺出版社／人才招聘，进入出版社。

核对完整稿的收件登记

先看提示

招聘表能把笔名和学校关联起来。稿件查询则需要她的署名与书名，两栏都填。

展开具体走法
  1. 在出版社「招聘」栏目读拟录用／复试名单，顾槐的来源是南溪第七中学，状态为「复试通过，待入职确认」。
  2. 点击投稿／稿件查询，作者／笔名填槐序，稿件名填河水向南。作者填顾槐也可。
  3. 查询结果登记号是 JA-080413-27，署名「槐序（顾槐）」，收件时间为 2008-04-13 19:26，完整稿共17项，正文16章加终章。
  4. 点登记表中「作者主页」的槐序／一棵树的背面进入博客。

送印日期2008-04-13博客当天的记录
文件名关键词河水向南小说书名；也可填「终稿」

结果是订单 QS-080413-118，送印时间20:06，文件《河水向南_终稿_末四章.doc》。点击打开旧系统保留的纯文本预览，读第十四、十五、十六章和终章。

继续看到最下方「旧预览属性」。文档最后保存于4月13日19:58，备注写着论坛正文停在十三章，「先不贴，明天再说」。接下来回到南溪文学论坛，查这天的旧帖。

查到那条零回复主题

先看提示

在论坛搜槐序和那天的日期，会被带回连载末页。那里还有一位当晚说自己刚回来的人。「关于本站」解释了零回复主题怎样查。

展开具体走法
  1. 回论坛首页，搜索槐序 2008-04-13。结果提示她当日可见记录仍只到第十三章，回连载末页看当天最近回复。
  2. 六月十一在 2008-04-13 23:34 留下「刚回来。十四章呢？」。在首页改搜六月十一 2008-04-13。
  3. 打开《毕业以后第一次回来》。帖子发表于23:52，回复数为0，编号NX-18471。他写明天要去见一个很久没见的人。
  4. 在帖尾打开旧站恢复说明，看「搜索与索引」和「主题编号」。下一步要结合槐序最后活动的时间与这条主题的编号。

请从「首页」开始搜索。若地址还停留在「散文随笔」或「投稿交流」等分区，先回首页清掉分区限制。

先看提示

六月十一的帖子在23:52发布，槐序最后活动在23:58。旧站说明说，主题创建时就会顺序分配编号，删除以后也可能留有缓存。试着查下一号。

展开具体走法

  3. 再回纯文本预览读《槐花开的时候》，对照六月十一的「明天去见」与槐序的「明天打电话」，也回看4月14日至16日的旧闻。
  4. 回到连载第十三章下方，看六月十一一直续到2024年的回复。主要调查记录至此可以相互对照。

把几份材料放在一起看

几个人名和账号怎样对应？
人物／账号对应与依据
槐序／顾槐出版社稿件登记直接注明「槐序（顾槐）」，校刊、招聘表均写南溪七中。
槐树下教师站的七中语文组签名，以及作文、二十二路、转出版社等发言，与顾槐的经历呼应。
六月十一／周禾6月11日毕业照、校刊《树下》、小满代订旧刊的姓名与论坛「姓周那位」的回复相互印证。
小说里的黎老师／陈禾顾槐与周禾的经历可以与小说中的许多细节对照，小说也写了作者为人物安排的选择。
顾槐最后发生了什么？

4月15日的失联报道交代了顾槐的姓名、年龄、工作和外出情况。4月16日事故后续写到一名31岁的中学女教师，随身有出版社联系卡、打印稿取件单和两支红笔，后由家属确认，已于15日凌晨去世。联系招聘、博客和打印记录，这组线索共同指向顾槐。后续报道按家属要求隐去姓名，读到这一页以后，仍需把前面的材料接起来。

老师为什么突然疏远了那个学生？

教师站2007年的边界讨论提到，周围开始出现难听的议论，「槐树下」担心学生知道以后与人争吵。陈老师的回复说，突然把孩子推开，他很可能理解成自己做错了。把这些发言与小说办公室里的一幕对照，可以读出她当时的顾虑，以及话没有向当事人解释清楚所留下的影响。

终章写着「明天再来」，现实里他们见到了吗？

终章写的是小说人物陈禾站在黎老师楼下，最后把见面推到明天。现实材料里，六月十一在4月13日23:52写明天去见一个很久没见的人，槐序在23:58写明天给一个人打电话，随后删帖；第二天发生了事故。作品留下的记录没有写出一场已经完成的重逢，两个人原本准备再开口的意思，留在了各自的帖子里。

长篇在4月13日已经写完并送交，公开连载仍停在十三章。最后四章与多年后的楼内回复放在一起，才补足这个停更的结尾。

几个时间点怎么排？
  • 4月13日19:26　出版社收到完整稿。
  • 19:58　打印预览属性显示最后保存。
  • 20:06　青石图文收到末四章打印订单。
  • 22:16　论坛第十三章发布。
  • 23:34　六月十一回复「刚回来。十四章呢？」。
  • 23:52　六月十一发布NX-18471。
  • 23:58—23:59　槐序发布并删除NX-18472。
  • 4月14日09:50左右　城北客运线发生侧翻。
  • 4月15日凌晨、下午　事故伤者去世，之后家属完成身份确认。
  • 4月16日　报纸刊发身份确认后续。

文学论坛首页有2016年最后备份的说明，连载里的后续回复续到2024年。按各条记录自己的时间阅读即可。

已经读完终稿，接下来还要查什么？

终稿末页的备注通往当晚两条旧帖。先查「六月十一 2008-04-13」拿到NX-18471，再根据旧站编号说明查NX-18472。最后把删帖、事故后续与终章再读一遍。这个压缩包的收尾落在这些材料的对照上，完成后可以继续回访所有旧页。
